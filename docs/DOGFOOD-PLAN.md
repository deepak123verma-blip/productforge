# Dogfood plan — one real product, day one of Stripe being live

A checklist, not a strategy. Goal: one real sale attributed to one real piece of content, producing the first honest numbers for the landing hero.

## The product
- [ ] **"KDP Listing Kit"** (or the strongest existing asset from the Tiny Treasures / AI Forge work): repackage as a multi-asset product — main guide (PDF), checklist (PDF), tracking spreadsheet (XLSX). 3+ assets so the "what's inside" section earns its keep.
- [ ] Price **$19** — above the low-ticket dispute band, low enough for an impulse buy from a Short.
- [ ] Write the description in the product's voice rules; generate nothing — this one is hand-made.

## The storefront
- [ ] Handle: `@deepak` (or the channel's name — whatever the audience already knows). Accent: `--mint`.
- [ ] Publish, confirm the safety pipeline passes in <10s, clear own review in the admin queue.
- [ ] Buy it yourself on a real card first (this doubles as the Phase 2 exit test): delivery email, both asset types download, evidence log populated, then refund it.

## The links (one per piece of content)
- [ ] `go/short-<topic>` — pinned comment on the best-performing existing Short
- [ ] `go/bio` — YouTube channel bio link
- [ ] `go/community` — one community-tab post
- [ ] Post ONE new Short about the product with its own `go/new-short` link — this is the attribution story.

## The numbers for the landing hero
After 2+ weeks, replace the fixture attribution card with the real row, whatever it says:
- [ ] `<content name> → <clicks> → <sales> → $<revenue>` from the Traffic by-content table, verbatim.
- [ ] Also update the miniature's Earned figure to the real month.
- [ ] If conversion is embarrassing, publish it anyway — "412 clicks, 2 sales" from a real screen still beats an invented number, and it tells us what to fix.

## Exit
- [ ] One payout of real money lands in a real bank account and reconciles to the cent against the statement.
- [ ] The by-content table answers "which content produced the money" truthfully for our own channel. If it can't, we are not ready to onboard anyone else.
